# TISCC regression schedules

These files are copied unchanged from the TISCC repository,
https://github.com/ORNL-QCI/TISCC, commit `1212aecf58b8cad7b3cd0a8069d596d147af37af`
(2025-02-25), directory `regression_tests/cases/`. Each `*.spec` is the expected output of
the command in the `*.case.sh` beside it; `-p` prints the full time-resolved hardware
schedule, `-r` the resource counts.

DE-AC05-00OR22725 with the Department of Energy."

No file here was modified. TISCC is described in T. LeBlond, J. G. Lietz, C. M. Seck and
R. S. Bennink, "TISCC: A Surface Code Compiler and Resource Estimator for Trapped-Ion
Processors", SC-W 2023, doi:10.1145/3624062.3624214, arXiv:2311.10687.
